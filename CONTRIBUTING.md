# Contributing to Aware

Read [current capabilities](README.md) and [neutral sources](workspaces/README.md).
Workspace's authored profile selects software; release maps cannot add packages.
Do not copy policy into the client or prune wheel contents to alter boundaries.

Root AGENTS.md and modular procedures retain their contributor command selection.
The new customer `aware init` is not a compatibility migration. Existing executions
keep their selected installed command; do not substitute the successor merely
because it offers initialization. [Pinned contributor history](https://github.com/aware-network/aware/tree/f760ac28066191e50ba12d249928c0fd553f79b4/protocols/agent/README.md)
remains available in a separate installation when explicitly selected.

Use tooling-issued Issue admission, exact scope and the original publication owner.
Preserve foreign work. No raw Git lifecycle, implicit service startup or automatic
retry of known publication. Push requires explicit current authorization.
[The complete envelope](releases/canonical-initializer-fs-v1/README.md) supplies retained source/legal inputs.
