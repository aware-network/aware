# Neutral source workspaces

One canonical authored source tree accompanies the 26 Aware packages selected
by Workspace's `portable_protocols` profile. All 1,023 selected source/build/legal
files retain their committed bytes and modes. The mapper consumes that accepted
index; it does not select, prune or rebuild software.

Use [the installed entrance](../README.md), not PYTHONPATH or an editable checkout.
Source READMEs and seed/resident examples are preserved history, not customer
instructions or additional capabilities. There is no `workspaces/previews` tree.

[The complete release](../releases/canonical-initializer-fs-v1/README.md) retains source/legal inputs and
maps each original coordinate. Root documents from the source capture remain
provenance there; root contributor governance stays separately selected.
No full producer discovery inventory, Service/API, ontology or Experience
dependency is introduced by this mapping.
