# Aware Specification Runtime

Dependency-free portable Specification definitions, phase acceptance evidence,
readiness evaluation, snapshots, strict codecs, and semantic transitions.

The V1 Gate body includes the authored nonempty `promise`, exact semantic-ref
configuration, and its sorted invariant closure. Specification and member keys
use the canonical filesystem-profile grammar; dependency targets and Gate
digests are validated before readiness evaluation.

This package is generated-free and materialization-independent. See
the owning `kernel-specification-core` spec for the wire and authority
contract. Filesystem parsing, source admission, Objects, and materialization
remain outside this package.
