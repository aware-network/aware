# Changelog

All notable changes to `aware-file-system` will be documented here.

## [0.3.8] - 2026-10-17
- Package the accepted retained private-directory IO and eleven evidence types
  with their two lossless owner codecs. Actual traversal reuses the original
  bounded reader and no-replace sequence writer.
- Preserve observed privacy/currentness, single-use execution, independent
  custody and once-only cleanup, including rejection-frame lifetime handling.
- Keep dependency bounds, generic IO and legal policy unchanged. Supplier
  packaging is not installed Workspace/Agent qualification or a public release.

## [0.3.2] - 2026-10-08
- Replace internal implementation recipes in package metadata with a neutral
  library description and explicit observed-state/confinement limits.
- Preserve the complete preceding README in the source repository's module
  reports; update public source/documentation coordinates.
- Runtime code, dependencies, entrypoints and the Apache-2.0 policy are unchanged.

## [0.1.1] - 2025-11-04
- Added a `[test]` extra bundling pytest dependencies for watcher suites.

## [0.1.0] - 2025-10-25
- Prepare package for open-source release: MIT license, expanded README, metadata updates, and test coverage confirmation.
