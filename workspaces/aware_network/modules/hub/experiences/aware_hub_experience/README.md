# Aware Hub Experience

This directory owns the product `aware-hub` experience package.

Current scope:

- compiled public discovery view-state contracts
- Hub SDK-owned view-state providers
- spec package surface under `docs/specs/`
- no custom Interface Host orchestration

Canonical direction:

- Hub distributes the map.
- Environment is the territory.
- Hub discovery is public/read-only before Identity.
- Interface is a shell that materializes panes via commit-driven attention/focus rails.
