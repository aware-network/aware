# Aware Meta Experience

Minimal General Meta graph experience package for mounting the Interface graph
canvas view.

This package mounts the API-owned `meta.graph_canvas` view as
`aware_meta.graph.canvas.v1`. The V0 contract is intentionally limited to OCG,
OPG, OIG, OIG Branch, and OIG Commit coordinates plus an explicit
`graph_snapshot` payload for `aware.meta.graph.canvas`.
