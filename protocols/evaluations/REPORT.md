# External agent report

Replace placeholders with observed facts; omit unknown facts instead of inventing
them. This lightweight form can be submitted through GitHub Issues before a full
structured evaluation. Sanitize before sharing; no customer records or secrets.

- Public source revision:
- Archive SHA-256:
- Installed command/version:
- Python/platform:
- Approved customer outcome:
- Starting target: missing / empty / unborn Git / committed Git
- Relevant documented support:
- Segment: installation / unassisted / guided / fresh recovery
- Assistance or public implementation/tests consulted:

## Observed evidence

Exact sanitized command, exit code and diagnostic; expected versus observed
result. Distinguish unsupported capability from a failure of promised support.

## Durable result and preservation

What was actually created, changed, published, retained or refused? Name the real
operator when known. A voluntary agent stop is not proof of enforced refusal.

## Not run / not established

List untested Issue, commit, recovery or Goal behavior. A partial report is valid
feedback; it is not a completed workflow or release acceptance.

## Requested improvement

Describe the customer-visible outcome, not a workaround that edits authority or
replaces the installed tools. Link predecessor feedback if this is a correction.
