# Consuming the Aware Goal reader preview

This is the consumer contract for the read-only preview, not permission to
contribute to the Aware source repository. Repository contributors additionally
follow the repository's root agent contract.

1. Use the installed `aware-goal-native` executable. Do not import Aware's
   development checkout, service internals or generated ontology to manufacture
   an unavailable operation.
2. Accept explicit repository, manifest and approved Goal/Lane/Phase coordinates
   from the customer or preparation owner. Do not select a Goal by recency,
   filename guesses, local cache or another agent's transcript.
3. Discover request coordinates through the installed operation. Preserve its
   exact JSON output; do not synthesize Gate digests or document identities.
4. Observe eligibility and direction through the same admitted provider. Save
   receipts outside authoritative Goal/Issue records. Report held, stale and
   refused results honestly; never edit records to turn them into success.
5. A positive result is direction context, **not authorization**. It does not
   approve a Gate, start pursuit, dispatch work, assign an Issue or authorize a
   commit. Follow the customer's separately authorized work process.
6. Preserve other executions' dirty work and evidence. A later execution obtains
   explicit coordinates and verifies retained direction with the installed
   currentness operation; it does not inherit authority from a transcript.
7. The sample Goal is synthetic read-only input. Its example references are not
   real actor actions, approval receipts or customer acceptance. Do not use the
   fixture generator as a customer Goal-authoring tool.

Current-epoch rejection is unsupported in this preview. Approval/pursuit
writers, Goal creation/import, manifest setup, Issue lifecycle, Service/API
and ActorWorld are unavailable. There is no automatic local fallback for a
service-owned target. Use the [quickstart](docs/quickstart.md) and retain the
exact installed distribution identity when reporting findings.
