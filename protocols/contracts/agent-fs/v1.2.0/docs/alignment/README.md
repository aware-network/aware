# Alignment center

Alignment makes the customer-approved direction and evidence discoverable across
executions. It does not evaluate Goals, assign Issues, establish actor identity
or authorize work. [CURRENT.md](CURRENT.md) is contextual documentation; the
owning Issue and actual operation receipts remain the relevant authority.

Record real customer objectives/acceptance and decisions first through Issue
updates. When an approved task requires shared documentation, add exact alignment
paths to its scope and update them as authored source through the same commit rail.
Link the Issue and evidence, distinguish observations from proposals, and preserve
history instead of replacing uncertain statements with unsupported certainty.

Follow [PROTOCOL.md](PROTOCOL.md). No service, ActorWorld, private strategy ledger
or inferred Goal coordinates are required for useful filesystem collaboration.
