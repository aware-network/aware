# Preview capability boundary

| Available installed operation | What it establishes |
| --- | --- |
| Eligibility request discovery | Exact committed Goal/document/Gate request coordinates |
| Phase eligibility observation | The neutral read-only eligibility decision and prerequisite evidence |
| Phase direction observation | A read-only, source-bound whole-document direction receipt |
| Phase direction currentness verification | Whether the supplied receipt remains current under the supported lineage contract |

The native CLI reaches Protocol admission and the real Goal SDK/provider. It
does not implement a second evaluator in a command, Skill or example script.
The payload is seven Aware neutral packages plus six third-party distributions;
its exact package list and hashes are in the attached payload manifest.
No Aware Service/API/DTO, ontology/ORM or Experience packages are included.

## Explicitly unavailable

- Customer Goal creation/import or manifest setup tooling.
- Goal approval, effectful pursuit, event publication and dispatch.
- Issue creation/claim/commit/closure commands in this native distribution.
- Current-epoch rejection evidence: **unsupported**, not a passed enforcement cell.
- Service/API authority, hosted multiplayer, apps and ActorWorld.
- A complete self-serve collaboration loop, Windows/macOS wheels, Python
  versions other than 3.12 or architectures other than Linux x86-64.

Eligibility never grants approval or work authority. Whole-document
currentness is distinct from Phase semantic-scope currentness. Writer command
absence demonstrates capability absence, not enforcement of an approval policy.

This early preview uses previously reviewed immutable payload bytes. Source
transparency, checksums and installed tests are provided; reproducible wheel
builds, exhaustive rights/privacy guarantees and registry publication are not
claimed. Component notices use a conservative account rather than claiming an
exact Rust binary linkage map or publisher-toolchain identity.
