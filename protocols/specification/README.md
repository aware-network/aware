# Specification drafts

Specifications make intended behavior and constraints explicit for cooperating
agents. After [Issue initialization](../INITIALIZATION.md), use separately
governed setup, typed input preparation, preview/apply and fresh observation
through `aware protocol` and `aware spec` from the same installation.

[WORKFLOW.md](../WORKFLOW.md) defines coordinates and guards;
[the typed example](../../workspaces/aware_kernel/modules/specification/sdks/specification/python/cli/examples/prepare_draft_input.py) prepares data, not authority.
Setup prepares directories and manifest binding, not documents or approvals.
Drafting uses the original staged semantic validation and no-replace publication.

Preserve partial publication and cleanup evidence. Drafts are not approval,
approved iterations, durable Issue bindings or Goals. Do not manufacture such
records to fill unsupported entrances. See [coherence](../COHERENCE.md).
