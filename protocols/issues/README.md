# Issue coordination

An Issue records an outcome, responsible execution, exact scope and durable
progress evidence. Shared rules let another execution continue genuinely
unfinished work. Scope is not a file reservation; preserve foreign work.

[Initialize explicitly](../INITIALIZATION.md), then follow
[the installed workflow](../WORKFLOW.md). Use `aware issue` for snapshot,
scope and progress operations. Init does not open an Issue or grant its authority.
Source effects, governed publication and closeout remain separate operations.

Retain publication, index, effects and cleanup evidence. Known publication must
not be automatically retried. A new execution needs fresh admission, not a
borrowed actor or serialized capability. Planned handoff is not crash recovery.
See [repository publication](../repository/README.md) and [coherence](../COHERENCE.md).
