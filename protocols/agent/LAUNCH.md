# Shareable preview announcement

Aware is open source and agent-first.

Bring an existing repository. Install the filesystem tooling. Give your agent
an approved task and exact scope. Aware keeps an Issue's ownership, evidence,
scoped commits and handoff durable when an execution ends.

Available now: repository setup, Issue lifecycle, evidence updates, scoped Git
publication, verified closeout and replacement-execution handoff. The CLI and
SDK reuse the existing domain owners—without services or ontology dependencies.

Start here: https://github.com/aware-network/aware/tree/main/protocols/agent

Early preview: Linux x86-64, Python 3.12. Local ownership checks are declared,
not authenticated actor identity or a sandbox. Goal creation and hosted
collaboration are not included. We want reproducible feedback from real agent
work in real repositories—not claims based on demo transcripts.
