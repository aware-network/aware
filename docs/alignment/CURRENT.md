# Current collaboration alignment

The [prepared entrance](../../README.md) uses the original SDK owners through
one installed `aware`. Coherence means shared rules, explicit admission and
recoverable evidence, not conflict-free execution. Readable protocols, tooling
installation, repository configuration and Service startup are distinct; this
filesystem composition starts no Service.

Saved receipts can be summarized or read exactly without replaying an operation.
The Workspace A1 mount requires prepared owner-admission inputs; it does not
admit A2 locks, positive tree-C completion, native receiving or materialization.
Raw deltas are change evidence, not inferred meaning or renewed authority.

The accepted successor is integrated and selected locally, not frozen or publicly delivered.
The [delivery pointer](../../releases/SELECTED.json) binds exact artifacts, not
package selection or authority. The contributor command stays unchanged.
[Whole-envelope carriage](../../releases/canonical-workspace-a1-fs-v1/README.md) is required.
Guards stay exact: no automatic refresh, mutation retry or inferred rollback.
Object/Meta/materialization and Service elevation remain separate lanes.
