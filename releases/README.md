# Filesystem distributions

[canonical-refusal-successor-fs-v1](canonical-refusal-successor-fs-v1/README.md) is a prepared,
unselected refusal-evidence successor. The proposed tree's original
[installer](../protocols/install.py) targets it; this is not public availability.
[SELECTED.json](SELECTED.json) still points to the delivered reviewed predecessor.
Package selection belongs solely to `portable_protocols`, not this pointer.
Whole-envelope source/notice carriage is required. Detached wheels, stripped
bundles and registry publication remain unaccepted. Integration, selection,
instruction freeze and publication are separately governed.
