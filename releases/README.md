unselected successor: one 42-package installation with init, Issue operations,

source, upstream inputs and raw audit must accompany the software. Six detached

Its accepted software and delivery receipts remain exact. This successor has
not been integrated, selected, frozen or delivered publicly. `portable_protocols`
remains the sole package selector; maps and pointers are delivery evidence.
