# Filesystem distributions

[canonical-init-summary-fs-v1](canonical-init-summary-fs-v1/README.md) is a prepared,
unselected init-summary successor. The proposed [installer](../protocols/install.py)
targets it; this is not public availability. [SELECTED.json](SELECTED.json)
still identifies the delivered human-evidence predecessor. Package selection belongs
solely to portable_protocols, not this delivery pointer. Whole-envelope source,
terms and notice carriage is mandatory; no wheel-only or stripped delivery.
Integration, selection, instruction freeze and publication remain separate gates.
