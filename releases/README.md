# Filesystem distributions

[canonical-reviewed-workflow-fs-v1](canonical-reviewed-workflow-fs-v1/README.md) is the prepared,
unselected reviewed-workflow successor. The original [whole-envelope installer](../protocols/install.py)
in this private proposed tree targets it; that is not a public delivery claim.
The unchanged [selection pointer](SELECTED.json) still selects the
[delivered A1 predecessor](canonical-workspace-a1-fs-v1/README.md).

Whole-envelope carriage is required. Six detached-wheel gaps and twelve raw
findings remain explicit; detached wheels, stripped bundles and registry
publication are unaccepted. Layout review, integration, selection, instruction
freeze and publication remain separate gates. `portable_protocols` alone selects
packages; this release directory is not a catalog or an authority provider.
