# Filesystem distributions

[canonical-reviewed-workflow-fs-v1](canonical-reviewed-workflow-fs-v1/README.md) is selected
locally. The [selection pointer](SELECTED.json) binds its accepted artifacts;
the original [whole-envelope installer](../protocols/install.py) is unchanged.
Public delivery is not yet authorized and instructions remain draft. The
[delivered A1 predecessor](canonical-workspace-a1-fs-v1/README.md) remains retained.

Whole-envelope carriage is required. Six detached-wheel gaps and twelve raw
findings remain explicit; detached wheels, stripped bundles and registry
publication are unaccepted. [Local selection](canonical-reviewed-workflow-fs-v1/LOCAL-SELECTION.md)
requires independent review; instruction freeze and publication remain separate
gates. `portable_protocols` alone selects
packages; this release directory is not a catalog or an authority provider.
