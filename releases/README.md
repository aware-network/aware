unselected successor. One 42-package installation supplies explicit init, Issue

in this private proposed tree targets the unselected successor; this is not a
claim about current public delivery. Instructions remain draft; integration,
selection, freeze and publication are separately governed.

unrepaired; detached wheels, stripped bundles and registry delivery are unaccepted.

owner-admission inputs; A2 and positive tree-C completion remain unaccepted.
