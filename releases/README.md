locally. The [selection pointer](SELECTED.json) binds its accepted artifacts;

is independently accepted. [Instruction freeze](canonical-reviewed-workflow-fs-v1/INSTRUCTION-FREEZE.md)
requires separate independent review; publication is separately authorized.

packages; this release directory is not a catalog or an authority provider.
